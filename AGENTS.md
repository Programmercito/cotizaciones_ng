# Agent Instructions

## Scope Discipline

- Implement only what the user explicitly requests. Do not add controls, features, content, animations, layout sections, or visual elements that were not requested.
- A request to make a specific element "look cool" applies only to that element. Improve its styling within the existing intent without inventing adjacent UI or functionality.
- Preserve all existing elements unless the user explicitly asks to remove or change them.
- If the requested scope is ambiguous, ask one concise question before making a potentially destructive change.
